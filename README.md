# Work Area

موقع Work Area، مساحة عمل الطالب، وهي جزء من ملخصات أبو عماد.

الموقع صفحة واحدة (`index.html`) فيها كل شيء: الصور والأيقونات مضمّنة داخل الملف، والخطوط تُحمَّل من Google Fonts.

## الأقسام

- الرئيسية: من نحن، لماذا تطلب منا، جهة الانتماء والتوثيق
- الخدمات والأسعار
- العرض الحالي
- كيف تطلب
- ماذا تستلم
- السياسات

كل أزرار الطلب تفتح محادثة واتساب مع 0538400646 برسالة جاهزة.

## النشر على GitHub Pages

من إعدادات المستودع: **Settings › Pages**، اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ. بعد دقيقة يصير الموقع متاحاً على:

`https://abdulazizemad2-ctrl.github.io/workarea/`

## التعديل

- الأسعار: مصفوفة `groups` داخل وسم `<script>` في آخر الملف.
- رقم الواتساب: المتغير `PHONE` في نفس المكان.
- السياسات: عناصر `<details>` في قسم `v-policies`.
